# 独自観点レビュアーへの入力の用意（PRレビュー用）

`development:reviewer` はgitを実行できないので、渡すものを事前に用意する。`--fix` が作業ツリーを書き換える前（独自観点レビュアーの起動前）に行う。

## 差分の大きさ（PR品質の観点）

PRの品質基準は、プラグインのルートの `review-rules.md` に従う。
測る前に、数えないテストのファイルを決める。

```bash
git -c core.quotepath=false diff --name-status -M <BASE_SHA>..<HEAD_SHA>
```

- `core.quotepath=false` を付ける（日本語のパスが引用符つきになり、除外が効かなくなるため）。
- リネーム（`R` で始まる行）をテストとして数えないときは、新旧両方のパスを渡す。

測れなかったら、その旨を添えて続行する。上限を超えていても停止しない。

## レビュアーに渡すもの

リポジトリのパス、PR番号、`review-rules.md` のパス、差分の大きさ（行数・バイト数・上限超過か。数えなかったテストがあれば、その件数も）。
