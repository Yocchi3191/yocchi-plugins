# PRに返信し、対応済みの印を付ける（Step 6）

投稿・操作に失敗したら、同じ操作を2回までリトライする（通信の瞬断や一時的なAPIエラーなら通るため）。それでも失敗した場合（認証切れ、権限不足、PRが閉じられた、など）は、Step 7へ進まず停止し、どこまで済んだか（返信・印を付けたもの）と対応報告の下書きをユーザーに渡す。印を付けた後に止まると、次の回は拾う指摘が無く、対応報告を出せないため。

本文はバッククォートや引用符を含みうるので、シェルに埋め込まず、リポジトリ外の一時ファイルに書き、`-F body=@<一時ファイル>`（`gh pr comment` では `--body-file`）で渡す。

## 1. 行コメントへの個別の返信

未対応として拾ったスレッドには、そのスレッドへ直接返信する。本文の1行目は目印 `<!-- fix-review:reply -->` にし、次を書く。

- 直した: コミットのSHA
- 答える: その回答
- 見送った・対応しない: その旨と理由
- 別issueに切り出した: issueのリンク
- 分割で別のPRへ移った: 「該当コードは PR #<番号> に移った」

```bash
gh api graphql -F threadId=<スレッドのid> -F body=@<一時ファイル> -f query='
mutation($threadId:ID!,$body:String!){
  addPullRequestReviewThreadReply(input:{pullRequestReviewThreadId:$threadId,body:$body}){comment{url}}
}'
```

応答の `comment.url` を控える（対応報告から返信へリンクするため）。

## 2. 対応済みの印を付ける

拾った指摘・質問すべてに付ける。直したものだけでなく、答えた・対応しない・見送った・別issueに切り出した・分割した・分割済み・別のPRへ移ったものも。全件の扱いはStep 4までに決めているので、付けられないものは無い。スレッドはresolveし、PR全体のコメントとレビュー本文は「解決済み」として非表示にする。拾わなかったコメント（お礼など）には付けない。

```bash
gh api graphql -F threadId=<スレッドのid> -f query='
mutation($threadId:ID!){resolveReviewThread(input:{threadId:$threadId}){thread{isResolved}}}'
gh api graphql -F id=<コメントまたはレビューのid> -f query='
mutation($id:ID!){minimizeComment(input:{subjectId:$id,classifier:RESOLVED}){minimizedComment{isMinimized}}}'
```

## 3. 対応報告

最後に、今回の対応全体をまとめたコメントをPRに投稿する（`gh pr comment <N> --body-file <一時ファイル>`）。本文の1行目は目印 `<!-- fix-review -->`。Step 7で再レビューを頼む場合（今回分割した、または重い指摘（Critical・Important、重いと見積もったもの）を直した回で、再レビューの回数が2回未満のとき）は、2行目を `<!-- fix-review:rereview -->` にする。見出しは次のとおりで、該当が無いものは省く。

- `## レビュー対応（<n>回目）` — `<n>` は数えた対応の回数 + 1
- `### 直したもの` — 指摘ごとに、場所・直した内容・コミットのSHA
- `### 対応しなかったもの` — 軽いと判断した、または誤りと判断した指摘ごとに、理由
- `### 見送ったもの` — ユーザーが見送ると決めた指摘ごとに、理由
- `### 別issueに切り出したもの` — 指摘ごとに、issueのリンク
- `### 分割したもの` — 分割した新しいPRの番号とリンク。再レビューが2回未満なら再レビューする旨を、2回に達していればまだ再レビューを通っていない旨を添える（レビュー結果はPR全体のコメントでスレッドに返信できないため、ここで返す）
- `### 分割済みだったもの` — 上に積んだPRの番号とリンク（再レビューの一文は付けない）
- `### 分割で別のPRへ移ったもの` — 指摘ごとに、移った先のPRのリンク
- `### 質問への回答` — PR全体のコメントやレビュー本文の質問への回答。行コメントの質問はスレッドで答えたので、1で控えた返信のURLだけを並べる
- rebaseした場合は、その旨
